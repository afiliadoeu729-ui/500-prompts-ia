# 500 Prompt Chains para IA — organizados por área

Pacote com **500 cadeias de prompts em português**, divididas em 12 categorias. Cada prompt é uma sequência de etapas separadas por `~`: primeiro a IA analisa e constrói contexto, depois produz, revisa e entrega o resultado final.

- **53 prompts** vêm do repositório público [MIATECHPARTNERS/PromptChains](https://github.com/MIATECHPARTNERS/PromptChains), traduzidos para o português, adaptados ao contexto brasileiro e redistribuídos por área (marcados com 🔁).
- **447 prompts** são novos, escritos no mesmo formato e nível de detalhe.

## Como usar

1. Abra o arquivo da área e escolha um prompt pelo índice do topo.
2. Copie o bloco de código inteiro.
3. Substitua cada campo `[ENTRE_COLCHETES]` (ou `NOME=[...]`) pelas suas informações. Quanto mais específico, melhor o resultado.
4. Cole na sua IA:
   - **Com uma extensão de fila** (como o [ChatGPT Queue](https://chromewebstore.google.com/detail/chatgpt-queue/iabnajjakkfbclflgaghociafnjclbem)): cole a cadeia inteira; cada trecho entre `~` vira uma mensagem enviada automaticamente, em ordem.
   - **Sem extensão:** envie a parte das variáveis junto com a primeira etapa e depois cada etapa seguinte, uma por vez, esperando a resposta.
5. Etapas que dizem "aguarde minha resposta" são interativas: responda antes de seguir.

**Dicas**

- Etapas que pedem "busca na web" funcionam melhor em IAs com pesquisa ativada.
- Prompts de saúde, finanças e questões jurídicas são educativos: valide as conclusões com um profissional.
- Use o prompt "Criar sua própria cadeia de prompts" (categoria Inteligência artificial) para montar cadeias novas no mesmo padrão.
